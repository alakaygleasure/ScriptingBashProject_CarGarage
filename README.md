# Bash Mini-Project

## Project title
Luxury Car Garage

The project is a record system for a Sports Car Garage and helps the intended users the employees how to view, update, move and look at records of what existing cars are on there system, as well as looking at import and export history of cars and what factors will effect i nf a car should be exported or add a price discount based on its existing records.
